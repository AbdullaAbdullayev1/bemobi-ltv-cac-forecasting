## 🎯 Project Overview

This project delivered end-to-end analysis across two core workstreams — customer economics and forward-looking revenue projections — to support strategic marketing and growth decisions.

## 🔍 Scope of Work

| Area | Description |
|------|-------------|
| **LTV Analysis** | Customer Lifetime Value modeling to assess long-term customer profitability |
| **CPA Analysis** | Customer Acquisition Cost breakdown across channels |
| **LTV:CAC Ratio** | Unit economics evaluation to measure marketing efficiency |
| **Revenue Forecasting** | Q4 revenue projections across **six markets** |

## 📁 Deliverables

- 📈 Excel workbooks with full calculations and data models
- 🖥️ PowerPoint presentations summarizing findings and recommendations
- 🗃️ SQL scripts used for data extraction and analysis
